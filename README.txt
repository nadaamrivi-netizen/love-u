WEBSITE UNGAKAPAN UNTUK FAIZAL — DARI NADA ♡
Tema desain: full girly pink, blush, dan ivory.

CARA MENAMBAHKAN FOTO DAN MUSIK SECARA PERMANEN DI FOLDER WEBSITE

1. Ekstrak anniversary_2_tahun.zip ke sebuah folder.
2. Masukkan foto utama kalian ke folder `assets` dan beri nama persis:
   `foto-utama.jpg`
3. Masukkan tiga foto galeri ke folder `assets/foto` dan beri nama persis:
   `foto-1.jpg`
   `foto-2.jpg`
   `foto-3.jpg`
4. Masukkan file audio yang kamu miliki ke folder `assets` dan beri nama:
   `lagu.mp3`
5. Buka `index.html` di Chrome atau Edge. Foto dan musik yang ada di folder
   akan dimuat otomatis. Tekan tombol Play untuk memulai musik.

CATATAN FOTO
- Nama file harus sama persis dengan petunjuk di atas. Kalau fotomu berformat PNG,
  ubah namanya/ekstensinya sesuai kode atau konversi ke JPG.
- Galeri sudah menyiapkan tujuh slot foto, dari `foto-1.jpg` sampai `foto-7.jpg`.
- Tombol upload di website masih tersedia untuk mencoba foto sementara, tetapi
  untuk foto yang tetap ada ketika dibuka ulang, masukkan file ke folder assets.

CATATAN MUSIK
- Gunakan file audio yang kamu miliki secara sah.
- Browser biasanya tidak mengizinkan musik otomatis menyala tanpa interaksi pengguna.
  Klik Play our song untuk memulainya.
- Tombol + tetap bisa memilih file audio sementara untuk sesi browser saat itu.

PENTING
- Jaga agar index.html, style.css, script.js, dan folder assets tetap bersama.
- Jika ingin mengirim website ke Faizal, kirim seluruh folder (atau ZIP yang sudah
  berisi foto dan lagu) atau unggah ke hosting. Jangan hanya mengirim index.html.
